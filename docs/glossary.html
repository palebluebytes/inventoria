Glossary

Every term the project uses with a specific meaning, defined once.

These definitions are a curated projection of the repository's domain glossary, CONTEXT.md, which stays the source of truth. Where a definition here disagrees with that file, this page is wrong, not the file. Definitions describe what each term is; the reasoning behind the model lives in the Explanation pages.

Storage core

Datom

The atomic unit of storage: a single fact, made of an entity ID, an attribute, a value, and a timestamp.

Used in: Introduction, State Is a Reading of the Past, EAVT Vocabulary

Ledger

The append-only, immutable datoms table holding the full chronological sequence of every datom. Current state is derived by reading this historical log, never by mutating it.

Used in: Introduction, State Is a Reading of the Past, EAVT Vocabulary

Projection

A derived, read-only view of current state, produced by folding the Ledger's datoms forward through a pure function. A Projection takes no runtime parameters: it returns the full enriched set for one kind of entity, and any date, slot, or range narrowing is applied afterward by the interface. It is the only way the application reads state.

Used in: State Is a Reading of the Past, EAVT Vocabulary

Provenance

The immutable original payload retrieved from an external API or scraper at the moment of ingestion, stored as a JSON blob alongside its extraction metadata: timestamp, source URI, and adapter version.

Used in: EAVT Vocabulary

Digital Twins

Digital Twin

A virtual representation of a physical or distinct external item, tracked through static or slowly-changing attributes drawn from external databases such as Open Food Facts for food or TMDB for media.

Used in: Introduction, EAVT Vocabulary

Meal Type

A standardized classification (meal_type) that organizes Consumption Events chronologically and logically in interface timelines.

Used in: EAVT Vocabulary

Habits

Habit Lineage

A single continuous habit that spans multiple immutable Habit Blueprints linked chronologically.

Used in: EAVT Vocabulary

Habit Blueprint

A strictly immutable definition profile establishing goals, schedules, and instrument requirements for a tracked behavior. A change to a schedule creates a new Blueprint in the Lineage.

Used in: EAVT Vocabulary

Schedule Rule

A flexible JSON definition shared by Habit Blueprints and Calendar Event Blueprints, describing recurrence frequency and constraints. It supports six paradigms (daily_multiple, weekly_days, weekly_flexible, monthly_fixed, monthly_relative, yearly_fixed), each carrying an optional until field, an ISO date marking when the recurrence ends.

Used in: EAVT Vocabulary

Sub-Target

A distinct, strictly identified temporal slot within a Schedule Rule, such as a specific time like 08:00. When a Blueprint uses Sub-Targets, a logged completion must explicitly reference one.

Used in: EAVT Vocabulary

Execution Event

A logged instance of a habit completion, recorded as a timestamped action in the Ledger, with qualitative and quantitative metrics held in a JSON blob. Its status is one of completed, exempt (a paused slot), or uncompleted (a later datom cancelling the most recent matching completion).

Used in: State Is a Reading of the Past, EAVT Vocabulary

Calendar

Calendar Event Blueprint

An immutable scheduled appointment or recurring reminder entity (prefix cal_event:) with a required start datetime (cal_event/dtstart), an optional end datetime and description, a Schedule Rule, and a boolean cal_event/tracking attribute. A non-recurring Blueprint is a single appointment with no Schedule Rule.

Used in: EAVT Vocabulary

Compliance Event

A Calendar Event Blueprint with cal_event/tracking: true. It requires explicit user confirmation per projected slot and writes an Occurrence Event on confirmation; a slot whose time passes unconfirmed is marked missed.

Used in: EAVT Vocabulary

Appointment

A Calendar Event Blueprint with cal_event/tracking: false. It is purely informational: it occupies a slot on the Agenda as context but requires no action and writes no Occurrence Event. Once its time passes, the slot fades to past with no failure state.

Used in: EAVT Vocabulary

Occurrence Event

A logged instance confirming that a projected Compliance Event slot actually happened, recorded as an OccurrenceAction in the Ledger. Its time is the millisecond the user confirmed, which may differ from the Blueprint's scheduled slot. Until confirmed, projected slots exist only in memory.

Used in: EAVT Vocabulary

Agenda

The tab and view presenting a unified, date-navigable picture of the day. It holds two sections: SCHEDULE, a chronological timeline mixing projected Calendar Event slots and timed Habit Sub-Targets, and HABITS, the Habit Blueprints without a specific intra-day time.

Used in: EAVT Vocabulary

Events

Consumption Event

A logged instance of a Digital Twin or recipe intake, recorded as a timestamped action in the Ledger, with nutritional metrics held in a JSON blob.

Used in: EAVT Vocabulary

Engagement Event

A logged instance of watching a movie or show, or reading a book, recorded as a timestamped action in the Ledger and linking to a media Digital Twin.

Used in: EAVT Vocabulary

Acquisition Event

A logged instance representing the ownership state of a physical Digital Twin, recorded as a timestamped action in the Ledger with a status of either owned or wanted.

Used in: EAVT Vocabulary

Notes

Checklist

An ordered, free-form scratchpad list of manually-ticked Checklist Items. It carries no Schedule Rule, no tracking, and no streak, and never appears on the Agenda.

Used in: EAVT Vocabulary

Checklist Item

A single user-authored entry in a Checklist, carrying a label and a checked or unchecked state. Ticking it produces no Execution Event or Occurrence Event; the tick is plain state.

Used in: EAVT Vocabulary

Note

A free-form, user-authored entry with a title and a text body, where the body merges concurrent edits from several devices without conflict. Distinct from the twin/note annotation attribute on a Digital Twin.

Used in: EAVT Vocabulary
