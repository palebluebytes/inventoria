EAVT Vocabulary

The entity prefixes and attribute namespaces the ledger actually uses.

Every row in the datoms table is a datom with four fields. The entity is a namespaced identifier, the attribute is a namespaced key, the value is a primitive or a stringified JSON blob, and the time is a Unix millisecond timestamp. The datom itself is Rich Hickey's Datomic model; the reasoning for storing facts this way is in State Is a Reading of the Past.

Entity prefixes

An entity id begins with a prefix that names what kind of thing it is. Projections scope their reads by these prefixes.

Digital Twins

Prefix Identifies Seeded from
gtin: A food Digital Twin keyed by barcode Open Food Facts
fdc: A food Digital Twin keyed by food id USDA FoodData Central
food:custom_ A custom or photo-based food Digital Twin Authored locally

tmdb:movie_, tmdb:tv_ A film or series media Digital Twin TMDB
isbn: A book media Digital Twin Open Library

Attribute namespaces

An attribute key begins with a namespace naming the family of facts it belongs to. The representative attributes below are a sample; the source under src/ is the exhaustive list.

Namespace Belongs to Representative attributes
food/ Food Digital Twins name, photo_base64
nutrition/ Nutrition panels on food-bearing twins (schema.org/NutritionInformation) info — one atomic panel blob (serving_size, calories, protein_content, fat_content, carbohydrate_content, …) plus the twelve Nutrition-Facts micronutrient extensions in grams (ADR-0030, no schema.org counterpart): vitamin_d, calcium, iron, potassium, vitamin_a, vitamin_c, vitamin_e, vitamin_b6, vitamin_b12, folate, magnesium, zinc
recipe/ Recipe twins (schema.org/Recipe) name, description, url, image, instructions (ordered HowToStep text), yield, ingredients (pure { ref, amount, unit } references — nutrition is derived, never stored)
media/ Media Digital Twins title, director or author, release_date, poster_url
twin/ Physical item twins name, brand, image, note, raw_provenance (the Provenance blob)
habit/ Habit Blueprints name, category, instrument, schedule_rules, replaces (the Habit Lineage link)
cal_event/ Calendar Event Blueprints dtstart, dtend, title, tracking, schedule_rules
event/ Every logged Event type, target, status, metrics, instantiation (a logged recipe's frozen Recipe Instantiation snapshot: based_on, yield, and per-row { ref, name, amount, unit, calories, protein, fat, carbs }), meal_type (the Meal Type), rating, season
settings/ Application settings scraper_proxy_url, tmdb_api_key, usda_api_key
notes/ The Notes and Checklist op-log op (one CRDT operation delta)
